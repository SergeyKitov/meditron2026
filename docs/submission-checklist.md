# Подготовка проекта к показу

Сверено с приложенным пользователем документом «Требования к оформлению.pdf» (05.10.2026). Это контроль комплекта для демонстрации, а не утверждение клинической пригодности.

| Требование к сдаче | Где находится | Состояние |
| --- | --- | --- |
| Цель, задачи, реализация и ограничения | [README](../README.md), [архитектура](architecture.md), [состояние кода](implementation-status.md) | Описано |
| Запуск, зависимости и инструкция использования | [README](../README.md), [run.md](run.md), `uv.lock`, `frontend/package-lock.json`, `compose.yaml` | Локальный запуск и проверки выполнены; Docker Compose на этой машине не проверен |
| Входные и выходные данные, API | [README](../README.md), [вход заключений](report-ingress-contract.md), [статусы записи](booking-feedback-contract.md), `/docs` после запуска | Описано для демо; реальный контракт клиники не согласован |
| Структура исходного кода, тесты, примеры | `backend/`, `frontend/`, `backend/tests/`, `frontend/tests/`, `fixtures/`, `config/` | Есть |

| Схемы и презентация | [цикл и UML](next-step-cycle.md), [BPMN](pitch/workflow.bpmn), [PDF](pitch/patient-pathway-pitch-v5.pdf), [PPTX](pitch/patient-pathway-pitch-v5.pptx) | Актуализировано под один шаг |

Перед показом на другом компьютере следует один раз выполнить `uv sync --frozen`, `npm --prefix frontend ci`, установить браузер Chromium для Playwright **только если нужны браузерные тесты**, затем `bash scripts/check.sh` и `bash scripts/dev.sh`. Для выступления достаточно локального интерфейса и PDF; доступ к интернету, реальной МИС, PACS и «Третьему Мнению» не требуется.

Матрица направлений и лабораторных условий имеет статус `HYPOTHESIS`; демонстрационный сценарий не является медицинским назначением. Числа синтетической оценки и экономики не следует выдавать за результат клинического пилота.
