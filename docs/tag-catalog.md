# Черновой каталог причин маршрутизации

[tag.json](tag.json) содержит **8 вариантов** для первой версии: маммография и КТ органов грудной клетки. [tag.source.json](tag.source.json) сохраняет все 21 строки присланной таблицы без изменений. Отбор короткий и практический; статистики частоты находок конкретной клиники у нас нет.

«Причина» здесь означает **почему предложен следующий шаг или специалист**, а не догадку о заболевании, вызвавшем находку. В JSON отделены: сигнал из структурированного заключения, кандидат на первого специалиста, понятное основание, возможные исследования **после решения специалиста**, недостающий контекст и условие открытия следующего шага.

| Вариант | Кандидат на следующий шаг | Почему |
| --- | --- | --- |
| BI-RADS 1–2 | Новый визит по одному SR не предлагать | Нет основания автоматически создавать лишнюю запись. |
| BI-RADS 3 | Согласовать контроль у специалиста по визуализации молочной железы | Вероятно доброкачественный результат может требовать контроля по утверждённому протоколу. |
| BI-RADS 4 | Специалист по заболеваниям молочной железы | Нужно выбрать способ диагностической верификации; рак по изображению не подтверждён. |
| BI-RADS 5 | Приоритетный разбор профильным специалистом | Высокая подозрительность повышает приоритет, но не заменяет морфологический диагноз. |
| Очаги на КТ ОГК при неизвестной цели исследования | Индивидуальный разбор, затем возможный пульмонолог | Одного числа очагов недостаточно для выбора срока, КТ, ПЭТ/КТ или биопсии. |
| Плевральный выпот | Врач текущего приёма / пульмонолог | Значимость зависит от объёма, симптомов и контекста. |
| Коронарный кальций | Оценка риска у терапевта, кардиолог при необходимости | Случайный кальций не означает автоматическую коронарографию. |
| Эмфизема | Терапевт / пульмонолог при необходимости | Нужна клиническая связь с симптомами и функцией дыхания. |

## Как это встраивается в Meditron

Это **справочный каталог гипотез**: приложение не читает `tag.json` во время обработки случая. В демонстрационных `config/rules.json` отражены направления и причины для BI-RADS 3–5, когда обе категории доступны. Для известной цели КТ и ненулевого числа узлов предложена консультация пульмонолога без автоматического выбора исследования или срока. Неизвестная цель КТ по-прежнему требует ручного решения. Правила создают проект со статусом `HYPOTHESIS`; пациент видит путь только после подтверждения его точной версии специалистом.

Парсер сейчас получает только `mmg_rads_right`, `mmg_rads_left` и `ct_lc_num`. Поэтому варианты по выпоту, кальцию и эмфиземе остаются **только в каталоге**: нужно согласовать точные коды и пути в реальном JSON/SR и расширить профиль. Текстовые `origin_labels` не применяются как поиск подстроки.

Даже после технического сопоставления специалист должен утверждать **точную версию одного следующего шага** до показа пациенту. При нескольких находках он выбирает приоритетный ближайший шаг; дальнейшее действие обсуждается после результата в новой версии. Перечень `optional_research_for_specialist` не означает автоматическое назначение исследований. Лабораторную подготовку специалист указывает отдельно, если она требуется для выбранной услуги.

Для активации нужны медицинское утверждение каждой строки, согласование сроков и исключений, сопоставление с каталогом услуг клиники, реальные обезличенные примеры SR и контрактные тесты. До этого каталог применим только к синтетическому демо и обсуждению с экспертом.

Проверить структуру: `python3 scripts/validate_tag_catalog.py` из корня проекта.

## Основания для выбранных развилок

- [ACR BI-RADS](https://www.acr.org/Clinical-Resources/Clinical-Tools-and-Reference/Reporting-and-Data-Systems/BI-RADS) задаёт категории и принцип согласованной итоговой оценки; [справочная карточка категорий](https://cs.acr.org/-/media/ACR/Files/RADS/BI-RADS/BIRADS-Reference-Card.pdf) различает 1–5.
- [Fleischner Society](https://pubs.rsna.org/doi/10.1148/radiol.2017161659) ограничивает применимость правил случайных узлов; [ACR Lung-RADS](https://www.acr.org/-/media/ACR/Files/RADS/Lung-RADS/Lung-RADS-2022.pdf) относится к скрининговой КТ. Поэтому `ct_lc_num > 0` при неизвестной цели не превращается в точный график повторной КТ.
- [Консенсус BSCI/BSCCT/BSTI](https://pmc.ncbi.nlm.nih.gov/articles/PMC7774698/) предлагает при случайном коронарном кальции оценивать изменяемые факторы риска; в большинстве случаев сама находка не требует дополнительной визуализации.
- Публичные примеры полей у [«Третьего Мнения» для маммографии](https://thirdopinion.ai/mmg) и [КТ ОГК](https://thirdopinion.ai/chest_ct) помогают выбрать кандидатов для маппинга, но не заменяют реальный контракт SR клиники.
